# 华为云前端部署与 Supabase 接入

前端静态产物存放在私有 OBS，通过 CDN 和自有域名提供 HTTPS 访问；浏览器加载前端后直接调用已有华为云 RDS Supabase HTTPS API，终端用户无需华为云账号。保留已有框架、构建环境和 OBS 发布方式，不新增独立部署 CLI。

## 托管前提

先读取项目、会话及已有环境记录；更新/回退沿用已核实的 OBS/CDN 绑定。既有记录属于非 OBS 托管时，保留历史并说明超出本 skill 范围，不改标为 OBS 或自动迁移资源。

托管配置读 [域名与托管](references/hosting.md)，发布、更新或回退读 [OBS 发布](references/obs-release.md)。缺少可用域名时，只在已确定的构建环境中准备产物、运行可用预览并列出上线清单；域名、证书及适用备案条件齐备后继续 OBS/CDN，不报告公网完成。

## 任务与工作流

1. **确定范围。** 区分 OBS 项目的环境检查、安装/准备构建环境、创建并部署、只接入 Supabase、更新、回退及环境/服务维护。只接入后端不隐含采购资源；仅有访问 URL 而无源码/发布权限时完成只读诊断并列出缺项，不宣称已改造应用。
2. **识别应用与静态边界。** 创建/修改应用时读 [前端构建](references/frameworks.md)，先确认源码、框架、实际路由及产物能否独立静态服务。新项目未指定时使用 React＋Vite＋TypeScript；Vue、普通静态网站和已有静态导出沿用原方案。SSR、服务端 API、运行时秘密需求单独说明；本 skill 不部署后端。完成条件是明确可静态发布，或列出受阻功能及额外后端需求。
3. **确定并核实构建环境。** 构建、工具缺失或维护时读 [构建环境](references/build-environment.md)，先确定产物来源或构建位置，再按项目约束检查该环境的 Node 与包管理器。优先复用已有构建产物或 CI；本地构建复用兼容的现有工具，版本不匹配时不自动安装、升级或切换本地 Node。OBS 仅接收静态产物。仅在查询/管理华为云资源时读 [认证](references/authentication.md) 和 [区域](references/regions.md)，核实账号归属、资源、部署权限、费用和已有记录。首次永久 AK/SK 默认通过已核实版本 DevKit 一次终端初始化；已有认证直接复用，特殊认证沿用专用流程。OBS 项目已有 Supabase HTTPS URL/公开 Key，且本次仅检查后端接入时，不强制新增华为云 CLI 认证。
4. **接入已有 Supabase。** 需要后端时读 [Supabase](references/supabase.md)，配置公开连接参数、真实 origin、回调、CORS 和 RLS。使用已核实的实际稳定入口配置回调；域名尚未就绪时先准备产物与本地预览，最终地址确定后更新配置并重新构建。没有安全可用的后端地址时，不扩张网络权限来掩盖缺项。
5. **构建、发布与记录。** 开始发布、续跑或回退前先读 [OBS 发布记录与验收](references/deployment.md) 和 [记录契约](references/record-contract.md)，在状态变化时写入环境、版本与检查事件。准备 OBS/CDN 的具体请求、资源/配置差异、费用和恢复点，在已有授权内执行。生产入口切换以及共享 DNS/CDN/委托修改，先展示本次差异、影响范围和恢复点并取得确认；新付费资源及授权外公网/数据库变更另行确认。首次登录、MFA、域名实名及备案由用户完成。仅检查或资源准备计划请求保持只读；必要工具只在已确定且授权覆盖的目标内准备；部署请求本身不授权修改本地 Node/包管理器，本地工具链安装或切换需用户明确要求。环境安装本身不意味着发布生产。
6. **验证与交付。** 按第 5 步加载的规则先校验产物再切换入口，用真实访问地址验收，失败按 OBS 恢复流程处理。只有全部必需检查通过才记录成功版本；缺项、诊断通过或全 N/A 均不能作为线上验收通过。

## 工具与边界

华为云资源优先 KooCLI，OBS 文件默认用 KooCLI 内置 `hcloud obs`，兼容已有独立 obsutil；构建复用已有 CI 或已确定的本地/容器环境。执行前核对本地帮助和当前官方 schema；工具缺失按对应构建/托管指引在授权内准备；安装受阻时说明缺口，不自建签名器或调用未公开接口。

查询分页完成才判定资源不存在。认证/权限/参数错误修正前停止重试；瞬时读取最多重试三次。异步创建或发布结果不明先查询任务及资源，不能盲目重复购买或发布；等待默认最多 30 分钟，超时记录 ID 供续跑。保留共享配置，不因缺域名、无配额或区域限制自动更换资源区域或购买数据库。

## 交付

报告构建环境与 OBS/CDN 配置、实际工具版本/镜像摘要、修改、产物、实际访问 URL（注明 HTTP/HTTPS、预览/生产）、当前及前一成功版本、验收与恢复结果、费用假设和阻碍。明确区分 **本地应用已验证**（实际应用通过本地构建与适用检查）、**环境已准备**（当前任务所需工具、资源和权限已核实，入口待验项单列）、**线上验收通过**（真实入口全部适用检查通过）；HTTP 页面可达不等于 HTTPS/Auth 通过。官方依据与运行限制随各操作指引提供；本地检查和用户报告不能代替目标账号及应用的实际验证。
